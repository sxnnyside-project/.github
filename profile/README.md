## 🧃 What this is ✦

**Sxnnyside Project** is the realm of **Sxnnyside Project Ecosystem** dedicated to the development of utility software and different utilities for everyday life.

The projects here have grown beyond a single context: developer tools, desktop software, mobile applications, libraries, and other things that make a particular part of the day a little less annoying.

Some are tiny. Some are not.

They all start with the same question: *"Why doesn't this exist yet?"*

### Philosophy

> *"Build the utility you wish you had."*

Sxnnyside Project is an IP-driven studio with its own opinions about software, design, and how things should feel.

Sometimes the answer is very technical.
Sometimes it's a tiny tool.
Sometimes it's both たぶん

<details>
<summary><strong>✦ What's in the stack and why</strong></summary>

| Technology         | Role                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| **C#**             | Business software and systems where .NET makes sense                 |
| **TypeScript**     | Developer tooling, applications, and ecosystem infrastructure        |
| **Astro**          | Product websites and content-driven experiences                      |
| **Dart / Flutter** | Mobile and cross-platform applications                               |
| **Tauri**          | Native desktop applications using web technologies where appropriate |
| **Swift**          | Native Apple software and platform-specific experiences              |
| **Bun**            | Runtime and tooling for TypeScript projects                          |

</details>

The stack adapts to the problem.
**Not the other way around.**
